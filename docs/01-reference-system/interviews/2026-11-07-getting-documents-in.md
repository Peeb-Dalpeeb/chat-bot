# Interview: Getting documents in

Category: Getting documents in (how documents get into the chatbot, including
tables, charts, and updates).

## Batch 1 (2026-11-07)

```
I'm studying how this chatbot system is designed so I can learn from it. Please follow these rules when you answer:

- Describe the architecture and approach in plain words. Don't include code, file names, function names, keys, passwords, or internal addresses.
- Mark each answer "confirmed in the files" or "not sure."
- If the files don't show something, say "not found in the files." Don't guess.

This batch is about how documents get into the system.

1. In two or three sentences, what is this chatbot for, and what documents does it answer questions from? What kinds of files are they (for example web pages, PDFs, structured data like XML, Word files, scanned images), and how do they get in: pulled automatically from an official source, uploaded by a person, or both?

2. Walk me through the steps from a raw document to "ready to be searched," in order. For each step, what kind of tool does the work (for example a PDF text reader, an image-to-text (OCR) tool, an AI model, or a person)? Does the system keep the document's structure, such as part, section, and paragraph numbers and headings? If so, how is that structure kept and carried along?

3. How are tables and charts handled? For example: kept as tables, turned into plain text, described in words by an AI model, or skipped? Is the result checked in any way to make sure the numbers and rows came through correctly?

4. What happens when a document changes or a new version is published? How does the system find out (on a schedule, by a person, or not at all)? Does it reload everything or only what changed? Are older versions kept, and does each stored piece of text record which version or date it came from?

5. What happens when a document fails to load or comes out garbled (for example missing sections, empty pages, or jumbled text)? Is anything checked automatically, does a person review it, and what happens to a bad document: skipped, flagged for a person, or loaded anyway?
```
