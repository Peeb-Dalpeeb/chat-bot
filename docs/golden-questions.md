# Golden questions

The project's test set: real questions with known correct answers. A bot is
only as reliable as we can show it to be, and this is how we show it.

**Target:** 30-50 questions, built up over time. Start with about 10.

## What makes a good set

Include a mix of:

- **Straightforward:** the answer is in one section.
- **Commentary:** the answer is in the Official Interpretations, not the rule
  text.
- **Multi-section:** the answer needs two or more sections.
- **Out of scope:** the documents don't cover it, so the right answer is to
  say so.
- **False premise:** the question assumes something untrue, and the right
  answer corrects it.
- **Reworded pairs:** the same question asked two ways, to test consistency.

Check every expected answer and citation against the eCFR text before adding
it.
