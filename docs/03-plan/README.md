# Phase 3: Plan

Not started. This is where our own design goes, written only after Phases 1 and
2 are done. Each design choice should point back to the findings or research
that support it.

## The plan must define

- **Who the users are** and what they'll ask.
- **What "reliable" means, as a number** (for example, the percentage of golden
  questions with a correct answer and correct citation).
- **What "consistent" means, as a number** (for example, the same answer on
  repeat runs and on reworded questions).
- **What the bot does when it can't answer** (refuses, says what's missing,
  points to a section).
- **How regulation versions and dates are handled.**
- **Which AI models to use, and the budget.**
