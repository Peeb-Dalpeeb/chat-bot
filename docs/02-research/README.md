# Phase 2: Research

Goal: learn how others build reliable chatbots, so our plan rests on evidence
and not only on the one reference system.

## Questions

- How do other industries (banking, healthcare, legal, government, insurance)
  build document-answering chatbots? What do they do about accuracy?
- What does current research say produces valid, reliable answers? This covers
  retrieval methods, citations, confidence, refusing when unsure, and
  evaluation.
- How does what we found in Phase 1 compare?

## How to record

- `industries/`: one file per industry or organization.
- `literature/`: one file per paper, guide, or topic.
- Every finding links to its source.
